# 链接解析去水印设计

## 目标

将“链接解析”改造成短视频作品解析入口。用户粘贴抖音、小红书或视频号分享内容后，系统解析出作品文案和无水印媒体文件，并在小程序里提供预览、复制文案、下载到本地/相册。

第一版覆盖抖音、小红书和视频号。

## 用户流程

1. 用户在链接解析页粘贴分享内容或短链接。
2. 前端提取第一个 `http/https` 链接，连同原始粘贴文本提交任务。
3. 后端识别平台并异步解析作品。
4. 任务成功后，前端展示作品类型、文案、媒体列表和下载按钮。
5. 用户点击下载，前端从后端本地媒体地址下载并保存到相册。

## 后端设计

链接解析任务仍使用现有 `link_parse` 任务类型，但结果结构升级为作品级数据：

```json
{
  "platform": "douyin",
  "media_type": "video",
  "caption": "作品文案",
  "assets": [
    {
      "type": "video",
      "source_url": "平台资源地址",
      "local_url": "/media/link_assets/<task_id>/video_1.mp4",
      "mime_type": "video/mp4"
    }
  ],
  "parse_method": "public_page",
  "download_status": "success"
}
```

后端新增平台适配层：

- 抖音适配器：短链展开、公开页面解析、`yt-dlp` 解析，失败后使用服务账号 Cookie 重试。
- 小红书适配器：`xhslink` 跳转、公开页面初始 JSON 解析，失败后使用服务账号 Cookie 重试。
- 视频号适配器：识别 `channels.weixin.qq.com` 链接，尝试公开页面解析和 `yt-dlp` 解析，失败后使用服务账号 Cookie 重试。
- 统一下载器：把视频或图片下载到 `MEDIA_ROOT/link_assets/<task_id>/`。
- 结果转换器：把本地文件路径转换为 `/media/...` 可访问地址。

Cookie 策略：

- 优先无 Cookie 解析。
- 无 Cookie 失败后，读取 `backend/data/cookies.txt` 作为服务账号 Cookie。
- Cookie 文件不提交到 Git。
- Cookie 失效时任务失败，并返回明确错误：`cookie_expired_or_required`。

## 媒体处理

本次“无水印”优先指平台解析出的无水印原始媒体资源。若平台只能返回带水印资源，后端再使用现有 ffmpeg delogo 处理作为兜底。

视频作品：

- 下载为本地 mp4。
- 返回单个 video asset。
- 需要时执行现有视频帧 OCR，作为 `video_text` 辅助字段。

图片作品：

- 下载所有图片。
- 返回多个 image asset。
- 不做图像水印修复，除非后续单独扩展图片去水印算法。

文案来源优先级：

1. 平台页面或解析器返回的标题/描述/正文。
2. `yt-dlp` 返回的 `title` / `description`。
3. 视频 OCR 文本。
4. 解析失败时不再用用户粘贴文本冒充平台文案。

## 前端设计

链接解析页保留一个输入框和提交按钮。结果区改为作品展示：

- 文案卡片：展示平台文案，支持复制。
- 媒体卡片：视频显示一个下载按钮；图片显示图片列表和逐个下载入口。
- 状态卡片：展示解析方式、下载状态、错误原因。

下载行为：

- 视频使用 `uni.downloadFile` + `uni.saveVideoToPhotosAlbum`。
- 图片使用 `uni.downloadFile` + `uni.saveImageToPhotosAlbum`。
- 如果开发者工具处于游客模式或缺少 AppID，保存相册可能失败，前端显示权限提示。

## 错误处理

- 不支持平台：任务失败，提示“暂只支持抖音、小红书和视频号”。
- 链接无效：前端阻止提交并提示输入有效链接。
- 解析失败：任务失败，保留平台返回或解析器错误信息。
- Cookie 缺失或失效：任务失败，提示更新 `backend/data/cookies.txt`。
- 下载失败：任务失败，不返回空的成功结果。

## 验证

后端：

- 抖音链接解析单元测试覆盖成功、Cookie 兜底、失败提示。
- 小红书链接解析单元测试覆盖视频和图片作品。
- 视频号链接解析单元测试覆盖成功、Cookie 兜底、失败提示。
- 下载器测试使用 mock URL，不依赖真实平台。

前端：

- 小程序构建通过。
- 链接解析页能展示视频、图片和错误状态。

手动验证：

- 使用真实抖音链接，确认返回本地视频地址和文案。
- 使用真实小红书视频链接，确认返回本地视频地址和文案。
- 使用真实小红书图文链接，确认返回图片列表和文案。
- 使用真实视频号链接，确认返回本地视频地址和文案。
